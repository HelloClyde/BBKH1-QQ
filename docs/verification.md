# 验证记录

## 独立构建

- 固定SDK：`58bb60d2cf9b7783f5bc31ed35d6e28606871ec7`。
- GNU MIPS：15.2.0，little-endian MIPS32软浮点，生产包不链接ARM库、解释器或JIT。
- 本地独立构建BDA：1759600字节，SHA-256 `203adfe5792370dde4ffd56c1240e1c51bc8dbcc947cee7b4149f090ec6e107f`；普通BDA标题/分类/资源范围/checksum及4MiB载入窗口均由构建器检查。
- 原生算法录制向量：491项通过，无原ARM库运行依赖。
- 离线模型使用实际链接MIPS BDA，覆盖扫码与确认、加密登录保存/恢复、好友/群、分组/搜索、文字发送/接收、群推送、三处拖动、头像、最近会话、本地历史恢复、清除确认/取消/失败、空列表加载与失败重试。报告位于`build/client/`，由`tools/test_mips.py`统一汇总；CI只上传合成数据模型证据。
- 首次身份工具验证两个设备得到不同随机密钥，并且再次运行保留已有身份。未在本次整理中替换任何真机身份、票据或消息。

模型时钟由测试显式提供，不用于真机性能判断。USB交接检查在实际等待循环的`fw_delay`入口推进时间，同时强制在交接提示绘制前暂停一次，覆盖标记已置位但等待起点尚未记录的调度边界；不向应用写入成功状态，也不依赖主机快慢跳过等待。

## 真机基线

整理前的已安装版本SHA-256为`109e1a472e2e32d4f6ecb454394450c1f9b54edd635234af5b79283938e2af32`。H1/Y100 V1.41、ESP32-S3 N16R8、ESP0.4.6独立联网；用户先后确认文字收发、分组/搜索、群自动刷新、滚动、头像缓存、有效登录恢复、本地记录重进保留、设置取消、列表加载态，以及顶部头像间距正常。
